What this project demonstrates

Fundamentals connected into real features.

The project moves from meaningful page structure to live API data. Every stage has a practical outcome that can be opened, tested and explained.

01 / Structure

Semantic HTML

Landmarks, heading order, forms, tables, labels and accessible native controls.

02 / Interface

Responsive CSS

Variables, Flexbox, Grid, reusable components, focus states and mobile layouts.

03 / Interaction

DOM and events

Selectors, event listeners, dynamic elements, feedback and form handling.

04 / Data

Arrays and objects

Rendering, filtering and sorting interface data with readable functions.

05 / Persistence

localStorage

Saving progress, preferences and useful articles across browser visits.

06 / Network

Async JavaScript

Fetch API, async/await and visible loading, empty, success and error states.
