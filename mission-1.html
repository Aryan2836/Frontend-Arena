    Mission 01 / HTML foundations

    HTML Foundations

    Understand what HTML does and build the minimum valid structure of a webpage.

    Easy50 XPStructureSemantics

    Concept

    HTML gives content structure and meaning

    HTML stands for HyperText Markup Language. A browser reads its elements to understand which content is a heading, paragraph, link, navigation area or main section.

    <!doctype html> <html lang="en"> <head> <meta charset="UTF-8" /> <title>My page</title> </head> <body> <h1>Hello, web</h1> </body> </html>

    Choose an HTML element for its purpose. CSS can change how it looks later.
