    Capstone flow

    One feature, several connected responsibilities

    1. The form validates and starts an asynchronous search.
    2. The response becomes the current articles state.
    3. The selected sort creates a derived copy of that state.
    4. Saved items use a second localStorage-backed array.
    5. A single render function keeps the visible list and count together.
