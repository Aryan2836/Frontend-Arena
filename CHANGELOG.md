# Changelog

All notable changes to Frontend Arena are documented here.

## 1.0.0 - 2026-09-20

### Added

- Professional Home, Learning and About pages
- Ten connected mission pages
- Shared mission navigation and progress tracking
- Responsive design system and accessible interaction states
- Project documentation and deployment instructions

### Changed

- Reorganized the original exercises into a coherent learning progression
- Unified colors, spacing, typography and reusable UI components
- Simplified the architecture to remain explainable with HTML, CSS and vanilla JavaScript

### Fixed

- Removed mixed mission ordering and misleading product areas
- Improved labels, focus states, status messages and mobile navigation
